# Weekly Tracker

A clean, minimalist weekly planner: weekly focus, goals, to-do list, habit
tracker, and a 7-day task grid — all in one page, inspired by paper planner
layouts. Personal use, no account or backend required.

## Features

- **Weekly focus** — one editable headline for the week.
- **Weekly goals** — 7 fixed, numbered goal slots with checkboxes.
- **To-do list** — an unbounded list for the week.
- **Habit tracker** — track habits across Mon–Sun with a goal and running
  streak.
- **7-day task grid** — Monday through Sunday task cards.
- **Week navigation** — move between weeks; past weeks stay saved. Unfinished
  to-dos can be carried over to the next week.
- **Keyboard shortcuts** — `←`/`→` change week, `T` adds a to-do, `G` jumps to
  the next empty goal, `H` adds a habit, `N` adds a task to today.
- **Local-only storage** — everything is saved to your browser's
  `localStorage`. No sign-in, no server, no tracking.

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL. To build a production bundle:

```bash
npm run build
npm run preview
```

## Stack

React + Vite + Tailwind CSS.
